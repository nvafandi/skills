# GLOBAL RULE: GitHub/Git Commit Conventions

**Always apply the github skill rules automatically for ANY git/GitHub operation - no mention needed.**

1. Before any git commit, check branch: git branch --show-current
2. Branch must start with PLAI-PRO or feature/PLAIPRO- - ask user if invalid
3. Commit format (MANDATORY): [PLAIPRO-XXXXX] {type}: {commit message}
   Example: [PLAIPRO-35563] docs: update github skill as global rule
4. Commit types: feat, fix, chore, refactor, docs, style, test, perf, ci, build, revert
5. Stage, commit, and push when asked to use GitHub

Full rules: github/SKILL.md
