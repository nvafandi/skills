# skills

Kumpulan skill untuk OpenCode / Claude / Cline / Gemini. Setiap skill ada di
`skill/<nama>/SKILL.md`, dengan modules/ dan references/ sebagai pelengkap.

Skill workflow SDLC berdiri sendiri (bekas sub-module `dont-be-dumb`, kini
independen): `storytelling-to-prd`, `prd-to-rfc`, `backend-architect-review`,
`task-breakdown`, `backend-implementation`, `code-review`, `security-analysis`,
`task-audit`, `documentation`, `project-context`, `resource-investigation`.
